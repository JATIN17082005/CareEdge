# CAREEDGE

AI-driven edge healthcare monitoring and risk prediction system.

## Overview

CAREEDGE is a healthcare monitoring prototype that combines physiological
data simulation, machine learning-based risk prediction, and a real-time
dashboard.

## System Architecture

Patient Simulation → Sensor Data → CLADE ML Model → Risk Prediction → Dashboard

## Project Structure

- `simulation/` — Patient and sensor data simulation
- `clade/` — CLADE machine learning and risk prediction
- `dashboard/` — Monitoring dashboard
- `data/` — Project data
